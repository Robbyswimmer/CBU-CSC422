# Fall 2025 archive — CSC 422

The Fall 2025 course ran under the old course code (**CSC 422**) and a
module-based layout (`Assignments/Module 0…4`, `Materials/Module 0…3`).

Fall 2026 renumbered the course to **CSCI 4220** and reorganised the repository
by week to match the published schedule. See `FA26/`.

**The full FA25 tree is preserved in git history** at tag `fa25-final`:

    git checkout fa25-final

or browse it at
<https://github.com/Robbyswimmer/CBU-CSC422/tree/fa25-final>

The two module overviews kept here are the only FA25 documents that had no
direct FA26 equivalent; their week numbering and course code are out of date.
