## How it is built

Every problem opens with a **worked example** — one instance of exactly the step
the problem then asks for, done in full with different numbers. One problem per
page, each followed by a ruled page for your working.

No code and no calculator: the few sigmoid and logarithm values you need are on
the cover page.
